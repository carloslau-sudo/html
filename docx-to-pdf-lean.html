How this works

The file you drop is parsed in-browser by mammoth.js, which reads the DOCX XML and converts it to clean semantic HTML — stripping the layout overhead that bloats Word's exports.

When you click Save as PDF, that HTML is rendered into a hidden frame and your browser's native print engine generates the PDF. Modern browsers subset fonts efficiently and apply standard PDF compression, which is why the output is so much smaller than what Word produces.

Some Word features don't survive the trip: custom page headers/footers, complex multi-column layouts, and exotic fonts will fall back. For the large majority of business documents — reports, memos, runbooks, change tickets — the output is visually equivalent at a fraction of the size.
