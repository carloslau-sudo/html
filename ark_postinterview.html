六、內心 reframe:Calling + Shelter 唔互斥

你之前誠實 surface 過:

「擔心如果 IT 搵唔到嘢做,可能要搵啲體力勞動、厭惡性工作,咁 Admin 始終都算係文職,容易落地啲。」

呢個 disclosure 講得出口需要勇氣。但 —

Shelter 同 Calling 唔係互斥
聖經入面,神嘅作為通常兩者一齊運作
人物處境 / 動機
亞伯拉罕離開 Ur 去迦南 = 呼召 + 逃離偶像文化
大衛洞穴歲月 = shelter,但神喺呢度塑造佢做王

摩西帶以色列出埃及 = 呼召 + 逃離法老追殺

6.1 點解誠實承認 shelter motive 反而 strengthen sustainability

如果 shelter motive 一直被壓住,佢會由側面爆出嚟。通常 12-18 個月後當 admin reality 開始磨人,你會 misread resentment 為「呢度唔係呼召」然後離開。

但如果你 surface 咗 shelter motive,你會識得辨認:

「呢度有 calling element,亦有 shelter element,而我而家 frustrated 嘅係 shelter expectation 未被 fully met,呢個唔等於 calling 唔在度。」

呢個分辨,只有對自己誠實過 shelter 動機嘅人先做得到。

6.2 Filter Question(自己心入面答)

誠實問自己

如果而家 100% 肯定 6/17 可以入職一份 60K 嘅 IT advisory contract,你仲會唔會想要方舟?

  • 「會」 → Calling weight 大過 shelter,可以 safely 行落去
  • 「未必」 → Shelter weight 大過 calling。唔代表唔應該去方舟,但代表你係 chosen,唔係 settled-for。呢個 ownership 對 18 個月後嘅心境有極大影響
